# Node.js REST API

## Tech Stack
- Node.js
- Express.js
- PostgreSQL
- Sequelize
- Swagger
- Jest


## Installation

npm install

## Environment Variables

DATABASE_URL=
PORT=

## Run Project

npm run dev

## Run Tests

npm test
